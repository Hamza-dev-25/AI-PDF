# PDF-QA

PDF-QA is an AI powered PDF Question Answering application built using RAG.

Users can upload a PDF and ask questions about its content. The application retrieves relevant information from the PDF and uses Mistral AI to generate answers.

## Technologies

Python

LangChain

Mistral AI

Chroma

Hugging Face Embeddings

Streamlit

## Features

PDF upload

Question answering

RAG based answers

Source page references

```bash
pip install -r requirements.txt
